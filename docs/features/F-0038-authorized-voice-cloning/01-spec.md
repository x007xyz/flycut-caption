# F-0038 项目说话人声音克隆：需求说明

## 要解决的问题

创作者希望外语版本保留自己的音色，但缺少受控的取样、授权与音色管理流程。

目标用户沿用 [VISION](../../10-product/vision.md)：以10–60分钟中文/中英混排口播的个人创作者为先，访谈与Agent场景仅按本候选明确范围支持。

## 范围

### 做

声音克隆：授权确认、从项目视频里选说话人片段作样本、音色管理与删除。

具体可观察行为以以下AC为界；复用现有Host、Provider、项目数据和统一时间映射。

### 不做

不自研口型同步，不随安装包分发Python，不开放任意外部录音克隆，不使用商用/分发许可不明的权重。

## 用户故事

作为使用FlyCut的口播创作者，我希望完成「项目说话人声音克隆」的完整操作，以便解决上述场景中的重复劳动与不确定性，并保留对素材和正式修改的控制。

## 验收标准

专用行为AC-1起列出，随后界面生命周期AC同样是验收项，不得用共用状态测试代替专用行为验证。桌面端优先，Web复用Host；平台补测项按其指定平台验收。

- **AC-1**：样本只能从当前项目视频选择说话人片段，展示时长和试听；没有有效片段不能创建，不提供任意录音上传入口。

- **AC-2**：每次创建前本人确认「这是我本人的声音，或我已获得说话人授权 / This is my voice, or I have the speaker’s permission」，记录时间、音色和来源；Agent/CLI不能代替本人确认。

- **AC-3**：云端发送前明确样本内容、接收Provider与留存条款；用户可取消，不支持克隆的模型明确提示并可选自带音色，不静默上传或训练。

- **AC-4**：克隆音色可命名、试听、用于单条TTS及删除；删除同时删样本并核实远端删除结果，结果不确定显示待确认，不伪报已删除。

- **AC-5**：**入口、空态与前置不足**：桌面端和Web连接Host时，复用该功能所属的现有项目、字幕、模型或任务入口；无目标/无模型/无资源时说明缺少什么并提供选择或配置入口，不显示假成功。无记录显示「暂无内容 / Nothing here yet」，已有项目编辑保持可用。

- **AC-6**：**加载与执行中**：加载显示「正在加载… / Loading…」，提交显示「正在处理… / Processing…」及可获得的进度；禁止重复提交，可取消的操作提供「取消 / Cancel」。返回上层或切换目标后迟到响应不能串项目。不能取消的外部步骤明确说明。

- **AC-7**：**正常与持久化**：完成后展示本需求专用结果及操作，只有Host确认写入/产物校验成功才提示「已完成 / Completed」；重开与第二个连接同Host的客户端读取结果一致。只读检查类保留报告而非虚构业务修改。

- **AC-8**：**失败、冲突与重试**：显示具体原因和「重试 / Retry」「返回 / Back」，保留用户输入和已有正式数据；保存结果不确定时先查询，不盲目重复副作用。版本过期提示「内容已更新，请重新检查 / Content changed. Review again.」，重新核对后才能提交。

- **AC-9**：**真实验证与界面回归**：每个新增/改动状态在中英文、明暗主题端到端覆盖，截图与录屏按本需求编号保存；按上述专用标准完成真实媒体/模型/接口/平台验证。桌面先验，Web复用同Host接口并列出远程环境结果；缺环境必须写Not run及阻塞，不能由mock替代。

## 成功指标

无授权请求数为0；创建与删除均有可核验记录，音色/样本不跨账户共享。

验收记录输入素材、模型/接口/平台版本、命令和结果；版本复盘按实测记录比较。没有埋点不编造线上转化或留存数字。
