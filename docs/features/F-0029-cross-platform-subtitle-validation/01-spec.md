## 范围

### 做

Windows 与 Cloud 渲染补测：WebView2 预览的一致性和流畅度、Windows 版 Skia 预编译包打包、Linux 无界面 Host 导出与随包字体。

具体可观察行为以以下AC为界；复用现有Host、Provider、项目数据和统一时间映射。

### 不做

不做通用关键帧编辑器、视频转场、B-roll或本需求之外的新特效；不重新选择已批准的渲染架构。

## 用户故事

作为使用FlyCut的口播创作者，我希望完成「Windows与Cloud字幕渲染补测」的完整操作，以便解决上述场景中的重复劳动与不确定性，并保留对素材和正式修改的控制。

## 验收标准

专用行为AC-1起列出，随后界面生命周期AC同样是验收项，不得用共用状态测试代替专用行为验证。桌面端优先，Web复用Host；平台补测项按其指定平台验收。

- **AC-1**：真实Windows WebView2安装包在1080p30fps播放/暂停拖动三画幅测试，与Skia帧比较换行相同、1080p包围盒偏移≤2px，前台重复测得掉帧<1%、拖动100ms内更新。

- **AC-2**：Windows包不依赖开发目录或系统字体，Skia预编译模块和完整字体加载成功；真实导入、预览、导出成片并用播放器打开。

- **AC-3**：Linux无图形桌面、无GPU、无系统中文字体的Host完成静态与动画导出，随包字体生效，结果与相同场景参考一致；记录发行版/架构和依赖版本。

- **AC-4**：不具备真实平台环境或任一指标失败时该平台保持未验证，不用模拟浏览器替代；报告阻塞、复现命令和支持矩阵，已有Mac行为回归。

- **AC-5**：**现有界面状态**：本需求补测已有产品，不新增「跨平台验证」页面。Windows现有播放器、字体载入、空字幕、导出排队/运行/完成/失败与取消，在中英文及明暗主题复测截图；出现缺陷在本需求修复并回归。

- **AC-6**：**Linux无界面行为**：Host仅用既有RPC/任务状态执行，返回结构化错误和进度，不依赖页面、窗口或GPU；字体/模块不可用时明确失败，不能生成替代字体成片冒充成功。

- **AC-7**：**支持矩阵**：报告列明操作系统、架构、WebView/Node/FFmpeg/Skia版本与真实输入输出；已测、失败、未测分开，证据和复现命令入需求目录。

- **AC-8**：**失败修复边界**：重试不得产生重复产物，原字幕/EDL不变；若补测发现需更换架构或扩大支持平台则回到需求确认，不把失败平台宣称已支持。

- **AC-9**：**真实环境门禁**：实际Windows安装包和Linux无桌面环境均须走通专用AC；无环境保留阻塞，不能用Mac上浏览器模拟替代。现有Mac路径完成回归。

## 成功指标

受测平台字体缺字/换行不一致数为0；产出可复现支持矩阵和实际安装/无界面导出证据。

验收记录输入素材、模型/接口/平台版本、命令和结果；版本复盘按实测记录比较。没有埋点不编造线上转化或留存数字。
