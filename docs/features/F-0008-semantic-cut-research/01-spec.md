# F-0008 去口癖语义层调研：需求说明

> 2026-11-05 流程调整：由原立项（01-intake）改名而来，内容未改。

## 来源

- 已确认 Epic 候选 E-06/7，对应路线图阶段一。批量编写日期：2026-11-05。
- 维护者原话：「是否可以一起确认，调用 subagent 同时处理多个任务，subagent 模型使用 deepseek flash」。本轮只准备可集中审阅的立项，不视为已批准各项产品细节。

## 要解决的问题

规则无法可靠判断“就是/那个”的语义用途、重复、句内改口和残句；未经评估就自动剪切可能改变原意。

## 目标用户与场景

对照 `docs/10-product/vision.md`：10–60 分钟中文口播创作者，字幕校对、粗剪、导出并继续发布。范围内各操作应让用户能检查结果，不能为了自动化隐去失败或覆盖选择。

## 竞品怎么做

资料来源为已存在的 vision.md 及所属 Epic（读取日期 2026-11-05）。Descript 为文本编辑/校对参考，剪映为后续精剪目标；各产品在本需求的具体版本、限制和行为本轮未外部核实，均待核实，不编造效果或价格。调研项会在研究阶段记录一手来源和日期；功能范围不依赖未经核实的竞品内部实现。

## 获客价值

对应愿景的创作者教程、开源社区与留存渠道：展示真实完成的字幕/粗剪工作流。核心是节省重复劳动、保持原始素材和用户确认权；调研结果不直接当成功能宣传。

## 优先级

P1。按已确认路线图阶段一推进；文档可并行准备，开发/调研仍遵守依赖门禁。

## 依赖

F-0001 调研报告确认后才能正式进入研究；立项允许提前做。使用至少两段未剪辑口播及人工标注，不把精校草稿当金标准。

frontmatter 的 depends_on 是脚本门禁；外部接口、真实配置和素材条件也必须在 PRD/研究计划列为前置条件，不能通过省略依赖绕过。

## 建议范围

- 明确输入为带原始时间戳和字词编号的转写，输出候选编号范围、类别、原因及置信信息的协议提案。
- 用同一人工参考集比较候选模型的误报、漏报、上下文完整性、延迟和调用成本，核验许可和服务隐私边界。
- 实验验证编号存在、范围连续、不能删成半句等程序校验，提出建议默认选中策略和失败降级方案，报告支持/不支持的场景。

### 不做

生产接入、确定未经评测的默认模型、训练自有模型、去重录挑优、无人工确认的自动应用。

## 不做的代价

规则无法可靠判断“就是/那个”的语义用途、重复、句内改口和残句；未经评估就自动剪切可能改变原意。 后续用户继续手工处理或无法可靠完成该流程；依赖本项的候选也不能用未验证结果推进。

## 已知约束与风险

- 调研类型，限制在可复现实验与结论；可能得出暂不实施某类语义剪辑的结果，不能为推进功能强行宣称可用。
- 不推翻 decisions.md；业务由 Host 插件实现，RPC 不接收任意本地路径，Tauri 保持外壳。涉及模型角色、AI配置或导出时复用现有能力，不另建平行体系。
- 桌面优先，Web 复用 Host 业务；Cloud 服务及多用户鉴权属于外部项目。媒体不改写，用户未确认的建议不破坏性应用。

## 验证与成功判断方向

可重跑的输入样本、人工标注、提示词/模型配置、脱敏输出、指标和成本表，逐项回答选型问题并形成 proposed ADR。

## 待澄清的问题与建议

建议以保守误删为优先指标，任何无法核验的输出不得应用。具体精度/成本门槛先在调研计划里提出，待人工基准可用再比较，不先写虚构达标结论。

## 结论

## 批量确认补充：先标记后删除与历史回退

自动分析只产生待确认建议，时间轴标红并同时提供文字/图标标记；正式 EDL、项目删除状态和常规导出不改变。用户可试听/预览按建议剪出的临时版本，逐条或批量确认后才写正式 EDL。取消/拒绝清除建议标记。应用前重新核验原文和剪辑版本；失效建议不得执行。已确认剪辑写入可持久化的操作历史，允许重开后回退到历史版本；回退也记录为新操作，不静默覆盖其他窗口更新。本轮不承诺恢复已被永久删除的源媒体。具体历史选择、待确认状态和保存失败交互进入 PRD。
