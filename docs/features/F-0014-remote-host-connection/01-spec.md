# F-0014 Cloud 客户端连接与会话：需求说明

> 2026-11-05 流程调整：由原立项（01-intake）和产品文档（02-prd）合并而成，内容未改；两者都已由维护者确认。

## 立项

### 来源

2026-11-05，维护者对批量立项建议回复“其他按你说的做”，明确批准将原 E-08/6 拆为连接会话和续传恢复；本项对应 E-08/6。原话及完整建议见 phase-one-batch-review.md。

### 要解决的问题

Web 用户连接远程 Host 时需要明确的身份与状态，并在网络中断后继续工作，避免上传重头开始、丢失任务状态或重复执行。将连接会话与大文件续传分开可独立交付并分别真实验收。

### 目标用户与场景

处理10–60分钟中文口播的个人创作者，在浏览器连接Cloud托管Host；自部署为次要单用户场景。

### 竞品怎么做

参考 vision.md 中的网页创作工具定位，具体会话及续传策略待核实（2026-11-05）；不以未经验证的竞品内部协议作实现依据。

### 获客价值

支撑Web免安装使用和长素材留存；以真实端到端流程演示，不能把连接成功宣传成阶段一全部功能已完成。

### 优先级

路线图阶段一平台补齐，候选已按维护者同意方向拆分。

### 依赖

无内部硬依赖；Cloud提供的真实鉴权会话契约、测试账户与可访问环境是外部前置。

### 建议范围

连接配置、Cloud鉴权会话接入、连接/过期/离线/重连状态、单用户自部署说明。重连只核验状态，不自动重发破坏性请求。

#### 不做

大文件断点续传、Cloud服务端、账号注册、计费、多租户鉴权。

### 规模检查

- [x] 用户可感知且可独立验收。
- [x] 按用户完成的一步拆分，不按前后端分层拆需求。
- [ ] PRD控制约10条AC，技术设计在真实协议明确后评估约两周规模。
- [ ] 外部协议/环境需落实，未落实不能宣称已完成真实验证。

### 不做的代价

用户无法可靠完成远程长素材工作流，断线可能造成重复操作或重传。

### 已知约束与风险

Cloud账号、计费与多租户属于仓库外。凭证不进静态页面、日志或公开链接；服务端仍是单租户且需鉴权反向代理。外部接口未定时PRD明确受阻，不用mock代替真实Cloud验收。

### 待澄清的问题与建议

分拆方向和范围已获本轮确认。具体会话/上传契约、最大文件限制及首发测试环境在PRD列为外部前置，不擅自发明Cloud已具备能力。

### 结论与确认记录

维护者已于2026-11-05回复“其他按你说的做”同意批量建议及远程Host拆分。本次把明确拆分方案落实为这两份立项；仅确认立项，PRD另行集中审阅。

## 产品需求

### 背景

2026-11-05维护者批量确认立项，并明确剪辑建议应先标红/预览、确认后删除，操作历史可回退。本PRD将立项范围落实为可验证行为，不把研究结论或外部服务假设当成事实。所属候选与来源见01-spec.md。

### 目标用户与竞品

10–60分钟中文口播的个人创作者。竞品定位沿用vision.md，具体功能/版本未外部核实均待核实；本PRD以已批准用户任务为依据，不承诺竞品内部协议兼容。

### 范围

#### 做

- 连接Cloud托管Host，使用Cloud现成会话/鉴权协议，明确连接、过期、离线和重连状态。
- 单用户自部署连接说明与鉴权反向代理要求；不建Cloud账号/计费服务。

#### 不做

大文件续传（F-0015）、Cloud服务端、多租户鉴权、自动重发导出/删除等副作用请求、以共享token充当Cloud登录。

### 用户故事

作为口播创作者，我希望浏览器明确告诉我连的是哪个Host，登录过期或断线时能安全重连，避免连错数据源。

### 验收标准

桌面端优先，Web开发模式连接同一Host验证共用业务；Cloud连接/续传另需真实远程环境。ASR Provider无关的功能不得按Provider写死分支；字词精确剪切仅看通过校验的实际结果。每个新增界面状态覆盖明暗主题与中英文，关键文案如下；测试名称带F-0014/AC编号。

- **AC-1 真实前置**：开发集成前须获得Cloud测试端点、会话协议、刷新/登出规则及账户环境；缺失时本需求明确受阻。客户端测试替身可验证UI，但不能宣称Cloud端到端通过。

- **AC-2 初始与配置**：未连接显示“连接Host / Connect to Host”及连接方式；配置无效地址/协议即时提示“连接地址无效 / Invalid connection address”，不发送凭证。目标Host身份在连接成功后可见，切换目标需明确确认。

- **AC-3 连接中**：显示“正在连接… / Connecting…”、取消，禁用重复连接；取消后的响应不切换当前Host或项目，原有正式数据不受影响。连接成功列出目标、能力和会话状态。

- **AC-4 鉴权失败**：无效/过期会话显示“登录已过期，请重新登录 / Your session expired. Sign in again.”和重新登录入口；拒绝访问显示“没有访问权限 / Access denied”，不无限重试，也不展示另一身份缓存的项目。

- **AC-5 临时断线**：显示“连接已断开，正在重连… / Disconnected. Reconnecting…”与手动重试/取消，按有上限的退避尝试。网络恢复后先核验身份/会话及任务快照，不重发原始副作用请求；失败显示“无法连接Host / Cannot connect to Host”及重试。

- **AC-6 编辑保护**：断线期间暂停依赖Host的新任务，保留当前内存编辑和可用临时恢复副本；不显示已保存。切换Host或登出前有未保存修改须沿用离开保护，绝不把旧Host副本写入新Host。

- **AC-7 会话更新与登出**：使用Cloud定义的刷新/登出流程，登出后停止相关订阅、清除会话凭据，不继续后台提交。未处理的恢复副本按既有规则隔离保存，不因登出静默覆盖或上传；重新登录同身份才可发现。

- **AC-8 凭证边界**：凭证不进入静态构建、日志、URL查询/公开链接或项目返回数据。生产Cloud连接使用其已确认安全通道，不能为了调试绕过鉴权；跨站/无权请求在真实环境被拒绝。

- **AC-9 自部署说明**：提供单用户部署、鉴权反向代理、Origin与连接配置的可复现实例；明确当前Host是单租户，页面可访问不代表具备Cloud账号隔离。不能把自部署通过当Cloud验收通过。

- **AC-10 验证范围**：真实远程环境完成登录、项目列表、打开、断线重连、会话过期、登出和换Host；记录真实结果。阶段一其他能力逐项单列验收，连接成功不等于全部Web功能已补齐。

### 成功指标

真实Cloud会话中断与过期各至少3次，重连不重复创建任务且不串Host；脱敏网络/日志检查无凭证泄露，自部署说明另行复现。

### 拆分检查

共10条AC，围绕本项用户任务形成可独立验收闭环。技术设计需依据真实调用点/外部协议复核约两周规模；无法一次完成则开发前回Epic拆分，不以多个未完成消费者混合上线。本批远程连接与大文件续传已按维护者确认拆开。

### 依赖与影响

按维护者批准拆分后的E-08/6，Cloud外部契约/环境是硬前置但非本仓库F编号依赖；共享协议/连接服务、安全相关改动需维护者在合并时放行。

统一遵守code-standards.md：固定commit逐AC验收，行为改动有Red check；真实模型/接口/素材/导出按改动范围实际验证，未执行列Not run。PRD确认不代表依赖已完成或允许跳过真实验证。

### 未决问题

Cloud端点、会话契约、测试账户尚需外部提供；其缺失不阻止审阅产品行为，但阻止集成开发与真实验收。接口确认若改范围则重审。
