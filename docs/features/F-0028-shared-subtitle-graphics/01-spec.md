# F-0028 共用字幕图形层落地：需求说明

## 要解决的问题

预览、Host硬烧与浏览器回退各自渲染字幕，字体和效果会不一致，新增特效难以可靠导出。

目标用户沿用 [VISION](../../10-product/vision.md)：以10–60分钟中文/中英混排口播的个人创作者为先，访谈与Agent场景仅按本候选明确范围支持。

## 范围

### 做

共用字幕图形层落地（按 ADR-0006）：现有静态样式迁到前后端共用的 Canvas 2D 图形层；预览改用图形层（拖动后在 `seeked` 补画、手绘阴影、读完整字体文件），Host 导出改为 Skia 字幕条带 + FFmpeg 叠加；修复导出不指定字体目录、成片字体与预览不一致的问题；浏览器回退导出（WebAV / ffmpeg.wasm）也改用图形层；在真实 Tauri 窗口复测 WKWebView 流畅度；macOS 打包验证。

具体可观察行为以以下AC为界；复用现有Host、Provider、项目数据和统一时间映射。

### 不做

不做通用关键帧编辑器、视频转场、B-roll或本需求之外的新特效；不重新选择已批准的渲染架构。

## 用户故事

作为使用FlyCut的口播创作者，我希望完成「共用字幕图形层落地」的完整操作，以便解决上述场景中的重复劳动与不确定性，并保留对素材和正式修改的控制。

## 验收标准

专用行为AC-1起列出，随后界面生命周期AC同样是验收项，不得用共用状态测试代替专用行为验证。桌面端优先，Web复用Host；平台补测项按其指定平台验收。

- **AC-1**：现有静态样式迁到前后端共用图形层，沿用全部用户可见样式选项与三画幅、主副双字幕；同时间截图换行相同且1080p包围盒偏移≤2px，抗锯齿差异单列。

- **AC-2**：前后端加载同一完整字体文件，用手绘阴影；预览按视频帧时间绘制，暂停拖动 seeked 后100ms内显示正确字幕；真实前台Tauri 1080p30fps多次测量掉帧<1%，否则继续优化不能宣称达标。

- **AC-3**：Host使用Skia字幕条带、frameKey复用及FFmpeg overlay format=yuv420；真实20/60分钟1080p导出记录总耗时和峰值内存，与同机ASS基线比较，静态不慢于基线1.2倍、动画不慢于1.5倍（建议门槛）。

- **AC-4**：WebAV与ffmpeg.wasm回退同样使用共用图形层，在Web真实导出对比帧；桌面仅Host导出，SRT/VTT/ASS文件和软字幕回归通过；macOS安装包中的.node和字体可加载，离线完整导出成功。

- **AC-5**：**入口与空态**：沿用现有播放器、字幕样式面板与导出入口，不新增「共用字幕图形层」技术入口。无字幕时不绘制字幕层；字幕字体载入前显示「正在加载字幕字体… / Loading subtitle fonts…」，不能先用替代字体伪装最终预览。

- **AC-6**：**载入与导出中**：字体就绪后再绘制首帧；导出沿用Host任务进度与取消。长素材加载/切换沿用项目打开状态，预览切换不阻塞其他视频操作；旧绘制任务不能画到新视频。

- **AC-7**：**正常与持久化**：原有样式字段和预设读取兼容，重开后外观保持；字体与场景版本可追踪。导出产物经校验后才显示完成，预览不产生多余项目编辑记录。

- **AC-8**：**失败与重试**：字体或原生模块加载失败显示「字幕渲染不可用 / Subtitle rendering is unavailable」及原因、重试，不静默改用ASS硬烧或系统替代字体。失败不损坏已有字幕/样式，导出半文件不标完成。

- **AC-9**：**真实使用与回归**：字体载入中、空字幕、正常预览、渲染失败、导出中/取消/失败/完成在中英文及明暗主题覆盖；真实Mac安装包和浏览器回退导出分别完成AC-1至AC-4，未验证的平台明确Not run。
