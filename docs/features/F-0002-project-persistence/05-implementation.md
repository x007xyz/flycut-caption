## 自行决定的事项

<!-- 开发中自己决定的事：决定了什么、为什么、影响哪条 AC。验收时汇总进测试报告 -->

- **自动保存放在项目服务里，不单独写 `useProjectAutosave` Hook**：订阅 `historyStore` 和 `appStore` 的工作在前端插件 `projectsClientPlugin` 里做，离开编辑器页面时不随组件卸载丢失计时和重试。（AC-3、AC-4）
- **字幕修改按引用判断是否变化**：`chunks`、`wordChunks`、样式对的数组 / 对象引用变了就算有修改，不做深比较；载入项目和转写结果写入编辑器后把当前引用记为保存起点，所以打开项目不会触发一次多余的保存。（AC-3）
- **字幕编辑框在失焦时提交修改**（现有行为），所以打字过程中本来就不会写；AC-3 的「连续修改不每次按键都写」由 1.5 秒停顿合并保证。（AC-3）
- **转写结果写入失败时保留并随自动保存一起重试**：否则 Host 短暂不可用时识别结果会丢。（AC-2、AC-4）
- **转写结果没写进项目前不保存修改**：`edits.json` 会覆盖句级字幕，没有转写时写一份空字幕会在重开时把转写盖掉。（AC-3）
- **「另存为新项目」的名称是「原名（副本）」/「name (copy)」**：新增文案 `components.project.copyName`；`projects.duplicate` 增加必填参数 `name`。（AC-25）
- **对话框文案按 PRD 改**：版本过新对话框的按钮由「确定」改为「关闭」；未保存离开对话框在重试期间「取消」也不可点（原型里可点），并且重试期间点遮罩不会关闭。（AC-24、AC-26）
- **媒体丢失时播放器区域显示横幅**：`FlyCutCaption` 增加可选参数 `playerPlaceholder`，没有媒体时用它代替「上传 / 示例视频」按钮，避免在丢失媒体的项目里误点上传又新建一个项目。（AC-27）
- **Tauri 权限增加 `core:window:allow-destroy`**：拦截关闭窗口（`onCloseRequested`）后要由前端关闭窗口，Tauri 要求这项权限。属于安全相关改动，需要维护者放行。（AC-4、AC-24）
- **时长用 FFmpeg 读，不用 ffprobe**：安装包只带了 `ffmpeg`，没有 `ffprobe`；从 `ffmpeg -i` 输出的 `Duration:` 解析。封面和时长在新建项目后后台生成，不改修订号（否则创建它的窗口第一次自动保存就会误报冲突）。（AC-14）
- **重开的项目媒体只有占位 `File`**：导出、波形、AI 面板、WebAV 引擎原来直接读 `videoFile.file`，重开项目后会读到空文件（导出会上传 0 字节）。新增 `src/utils/mediaSource.ts` 统一按来源读取（浏览器文件、桌面路径、Host 项目媒体）；波形只在知道文件大小且不超过上限时读取。（AC-6）
- **载入项目里的样式时不再按画面尺寸推断画幅**：原逻辑在视频尺寸变化时自动设置 `aspectPreset`，会覆盖用户保存的画幅；`appStore.subtitleStyleRestored` 标记样式来自项目。（AC-3、AC-5）

## 与设计的偏差

<!-- 实现时改变了设计的地方及原因；重大偏差要回到 03-design.md 修改并重新确认 -->

- 清单 2–5 合并成一次提交：保存请求、失败重试、冲突和离开保护共用同一套保存状态机，拆开提交中间状态不可用。
- 清单 7 的 Gateway 插件路由机制和带 Range 的项目媒体地址在清单 1 里已经做了（Web 端重开项目要能播放），清单 7 只剩验证。
- 样式对放进 `appStore`（`subtitleStylePair`），没有新建单独的样式 store；`partialize` 不包含它，不写 `localStorage`。

## 遗留问题

- **长视频打开慢，未达成功指标「60 分钟视频 3 秒内可编辑」**：浏览器里实测 6.9 秒，Host 只占约 65 ms。时间花在前端：字幕列表没有虚拟化（1200 条全部渲染文本框），`historyStore.setTranscript` 还会把整份转写打印到控制台。转写完成后载入字幕走的是同一条路径，不是本需求引入的；本需求不改编辑器渲染，建议单独立项（字幕列表虚拟化）。

- 离开编辑器前的保存没有超时：Host 收到请求却一直不返回时，点「我的项目」会一直等，不弹对话框。Host 断开时请求会立即失败，不受影响。
- 转写在用户离开该项目后完成且写入失败时，只在用户回到该项目并触发保存时重试；不在首页提示。
