# F-0046 单片段竖屏字幕视频导出：设计

## 方案

- `export.start` 新增 `crop: '9:16'`：在字幕叠加前对视频做居中裁切 `crop=ih*9/16:ih` 并缩放 1080x1920；硬字幕场景按 1080x1920 校验。
- 客户端 `useClipExport`：取已确认短片范围与全局 EDL 的交集生成 segments，只用片段内保留部分；字幕场景复用 F-0028 图形层（9:16 安全区），输出时间从 0 开始。
- ClipsPanel 每个已确认短片增加「导出竖屏」，显示进度/完成/失败；媒体缺失、片段无保留内容、字体不支持由现有导出/Host 报错阻止。
- 产物经 Host 导出并保存，原视频和项目不变。
