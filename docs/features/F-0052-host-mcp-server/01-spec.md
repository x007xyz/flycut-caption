目标用户沿用 [VISION](../../10-product/vision.md)：以10–60分钟中文/中英混排口播的个人创作者为先，访谈与Agent场景仅按本候选明确范围支持。

## 范围

### 做

MCP Server：复用 CLI 的应用服务，发布到 MCP / Skills 市场；建议需用户确认，破坏性操作需客户端二次确认。

具体可观察行为以以下AC为界；复用现有Host、Provider、项目数据和统一时间映射。

### 不做

## 用户故事

作为使用FlyCut的口播创作者或调用其Host的Agent用户，我希望完成「MCP Server与Agent接入」的完整操作，以便解决上述场景中的重复劳动与不确定性，并保留对素材和正式修改的控制。

## 验收标准

专用行为AC-1起列出，随后界面生命周期AC同样是验收项，不得用共用状态测试代替专用行为验证。桌面端优先，Web复用Host；平台补测项按其指定平台验收。

- **AC-1**：MCP复用CLI的Host应用服务，公开项目/媒体/转写/建议/新产物导出等工具及结构化schema，读取任务状态，不新增独立业务或前端Hook服务。

- **AC-2**：连接须通过Host鉴权，凭据和其他项目无关数据不进入工具描述/日志；无效参数、断线、超时和工具失败返回明确错误而不是空成功。

- **AC-3**：剪辑与片段建议返回待确认ID和客户端入口；删除项目/覆盖文件必须由客户端本人确认，工具调用或提示注入不能自己批准，重试不重复副作用。

- **AC-4**：至少一个真实MCP客户端从创建项目到真实转写/新文件导出走通并核对UI；交付安装说明与市场上架材料，发布市场需另获对外发布授权。

- **AC-5**：**协议发现与空结果**：真实MCP客户端可发现工具/schema与说明，空项目/建议返回结构化空集合；没有Host连接时给出配置说明，不新增MCP专属产品页面。

- **AC-6**：**执行中**：长任务返回任务ID和状态查询方式；客户端断开不丢Host状态，取消须说明停止等待或取消任务的实际效果，不能误报。

- **AC-7**：**正常结果**：工具结果含目标与产物ID，可在UI查看；只有Host确认完成才返回完成状态；协议层不把提交成功等同媒体处理已完成。

- **AC-8**：**错误与待确认**：无效schema、鉴权、目标不存在、版本冲突分别可识别；删除/覆盖返回客户端待确认请求，不允许工具自行提交批准，重试复用原请求身份。

- **AC-9**：**真实验证**：至少一个真实MCP客户端完成专用AC；客户端确认/错误状态在现有UI覆盖中英文与明暗主题，协议返回验证schema，不要求MCP工具另建主题界面。

## 成功指标

真实客户端工具闭环可复现；同请求去重、确认门禁与凭据隔离成立。
