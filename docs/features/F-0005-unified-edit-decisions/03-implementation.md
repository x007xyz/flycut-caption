## 自行决定的事项

- 微秒半开删除并集为唯一真源；deleted 字段保留为兼容显示投影。任何文字校对均不改变源媒体时间戳。
- 持久记录只存剪辑，普通 undo/redo 仍是会话内快照；历史回退保留当前校对、译文和样式。
- 建议只在临时 store 中存在，确认前不保存、不进入恢复副本和导出；基准改变后拒绝确认。
- 旧项目只读派生 legacy-export EDL，下一次写入才持久化；格式升级复用已有备份机制，不在读操作中改原始文件。
- 保存回执丢失先读回比较，再决定恢复是否成功；保存中产生的新修改继续 flush，不能直接误报历史读取失败。
- WebAV 对每个 sprite 使用精确的 EDL 段时长，抵消 MP4Clip 在编码样本边界多带一帧的问题。
- 非本需求范围的旧 ASR 时间戳仍沿用既有输入；这里不宣称已完成听校或修复识别对齐。

## 与设计的偏差

- 一个纯核心模块代替多个小文件；映射顺序扫描而非二分，60 分钟/1 万编辑单元的实测单次删除最大 56.19ms。
- 计算为同步原子提交；只在历史回退等待 Host 时显示 updating，不伪造异步计算状态。
- 原计划逐项小提交调整为一组跨消费者的实现提交，再加一个独立 WebAV 修复提交；旧 store、导出和持久化必须同时切换，避免中间状态混用两套时间真源。
- 原生测试使用独立 app identifier 和测试数据目录；测试项目使用真实 COSCUP 素材及已有转写，缩小字幕条数只为控制自动化界面的可访问性树规模，不改变媒体、EDL 或导出代码路径。

## 发现并修复

- 新 EDL 路径必须裁掉从 0 开始的尾段；旧 RPC 与迁移保留原有 fast path 语义。
- 仅比较总时长时，切点画面仍可能停留在前一段；使用共享的全局 fps filter 消除，新增逐帧和音频标记断言。
- WebAV 在样本边界为两个保留段各多带一帧；用精确 sprite 时长修复后，真实浏览器成片从 2.566641s 回到 2.5s，切点前后画面仍匹配源时间。
- 快速删除后立即打开历史会碰到首个保存仍在进行；改为继续 flush，历史读取不再被误报为失败。
- 媒体元信息尚未加载时保留百分比使用 EDL 原时长，避免 Infinity；E2E 覆盖。
