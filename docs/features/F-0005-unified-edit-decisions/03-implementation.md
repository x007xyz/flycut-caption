## 自行决定的事项

- 微秒半开删除并集为唯一真源；deleted 字段保留为兼容显示投影。任何文字校对均不改变源媒体时间戳。
- 持久记录只存剪辑，普通 undo/redo 仍是会话内快照；历史回退保留当前校对、译文和样式。
- 建议只在临时 store 中存在，确认前不保存、不进入恢复副本和导出；基准改变后拒绝确认。
- 旧项目只读派生 legacy-export EDL，下一次写入才持久化；格式升级复用已有备份机制，不在读操作中改原始文件。
- 保存回执丢失先读回比较，再决定恢复是否成功；保存中产生的新修改继续 flush，不能直接误报历史读取失败。
- 非独立评测的旧 ASR 时间戳仍是既有输入，本需求不宣称已完成听校或修复识别对齐。

## 与设计的偏差

- 一个纯核心模块代替多个小文件；映射顺序扫描而非二分，当前基准满足本机 200ms 目标。
- 计算为同步原子提交；只在历史回退的 Host 等待期间显示 updating，不伪造异步计算状态。
- 原计划逐项小提交调整为一份跨消费者的实现提交：旧 store、导出和持久化必须同时切换，避免中间提交混用两套时间真源。
- 真实桌面测试采用独立 app identifier 和数据目录；开发二进制不被 UI 工具识别，因此另包临时测试 .app；不会改正常 FlyCut 项目。

## 发现并修复

- 新 EDL 路径必须裁掉从 0 开始的尾段；旧 RPC 与迁移保留原有 fast path 语义。
- 只有总时长正确时，切点画面仍可能停留在前一段；使用共享的全局 fps filter 消除，新增逐帧和音频标记断言。
- 原生 Node 直接加载 timeUtils 时需显式 `.ts` 扩展名；修复后常规测试恢复全绿。
- 媒体元信息尚未加载时保留百分比使用 EDL 原时长，避免 Infinity；E2E 覆盖。
