# F-0009 去口癖语义层实现：需求说明

> 2026-11-05 流程调整：由原立项（01-intake）和产品文档（02-prd）合并而成，内容未改；两者都已由维护者确认。

## 立项

### 来源

- 已确认 Epic 候选 E-06/8，对应路线图阶段一。批量编写日期：2026-11-05。

### 要解决的问题

用户仍要手工发现规则层无法判定的口癖、重复、改口和残句，缺少可解释并可确认的语义剪辑建议。

### 目标用户与场景

对照 `docs/10-product/vision.md`：10–60 分钟中文口播创作者，字幕校对、粗剪、导出并继续发布。范围内各操作应让用户能检查结果，不能为了自动化隐去失败或覆盖选择。

### 竞品怎么做

资料来源为已存在的 vision.md 及所属 Epic（读取日期 2026-11-05）。Descript 为文本编辑/校对参考，剪映为后续精剪目标；各产品在本需求的具体版本、限制和行为本轮未外部核实，均待核实，不编造效果或价格。调研项会在研究阶段记录一手来源和日期；功能范围不依赖未经核实的竞品内部实现。

### 获客价值

对应愿景的创作者教程、开源社区与留存渠道：展示真实完成的字幕/粗剪工作流。核心是节省重复劳动、保持原始素材和用户确认权；调研结果不直接当成功能宣传。

### 优先级

P1。按已确认路线图阶段一推进；文档可并行准备，开发/调研仍遵守依赖门禁。

### 依赖

F-0008 调研报告和 F-0007 验收确认后才能开发。当前可先写产品层 PRD，模型/协议性能承诺标为受调研结论约束，结论改变已确认 AC 时重新审阅。

frontmatter 的 depends_on 是脚本门禁；外部接口、真实配置和素材条件也必须在 PRD/研究计划列为前置条件，不能通过省略依赖绕过。

### 建议范围

- 按 F-0008 的已确认研究结论，使用用户已经配置的 AI 模型分析，不引入平行模型设置。
- 语义建议与 F-0007 进入同一检查/确认流程，显示原文、区间、类别及原因；仅接受校验有效的编号范围，应用后写 EDL并可撤销。

#### 不做

未经研究确认的自动阈值或默认模型、重录挑优、整片脚本重写、自动删除低置信建议、自建模型服务。

## 产品需求

### 背景

2026-11-05维护者批量确认立项，并明确剪辑建议应先标红/预览、确认后删除，操作历史可回退。本PRD将立项范围落实为可验证行为，不把研究结论或外部服务假设当成事实。所属候选与来源见01-spec.md。

### 目标用户与竞品

10–60分钟中文口播的个人创作者。竞品定位沿用vision.md，具体功能/版本未外部核实均待核实；本PRD以已批准用户任务为依据，不承诺竞品内部协议兼容。

### 范围

#### 做

- 按F-0008结论接用户已配置AI模型，分析语义口癖、重复、句内改口及残句。
- 与规则层共用候选格式、时间轴标记、试听/临时预览和人工确认。
- 自动剪辑建议统一遵守修订后的 F-0005：建议是临时层，时间轴标红并有文字/图标；临时预览不修改正式 EDL/字幕删除状态，未确认内容不进入正常导出。逐条/批量确认才提交正式剪辑和持久化操作历史；取消只移除标记。历史可在重开后预览和回退，回退先确认并保留新记录。历史回退只恢复剪辑决策，不撤回后来完成的文字校对。

#### 不做

自动无确认删改、重录挑优、平行AI设置、无评测支持的算法/阈值、服务端计费体系。

### 用户故事

作为口播创作者，我希望AI指出需要语境才能判断的重复和改口，告诉我原因，让我听过再决定。

### 验收标准

桌面端优先，Web开发模式连接同一Host验证共用业务；Cloud连接/续传另需真实远程环境。ASR Provider无关的功能不得按Provider写死分支；字词精确剪切仅看通过校验的实际结果。每个新增界面状态覆盖明暗主题与中英文，关键文案如下；测试名称带F-0009/AC编号。

- **AC-1 未配置**：无AI模型时显示“配置AI模型以分析语义口癖 / Configure an AI model to analyze contextual fillers”，规则层继续可用。不能静默切换到收费服务或阻止正常编辑。

- **AC-2 范围与请求**：只发送用户主动请求范围的文本、必要上下文与编号，不上传源媒体；请求前显示发送范围和目标模型。输入/输出编号协议与支持类别以F-0008已确认结果为准，研究未确认不得开发。

- **AC-3 批次进度**：显示总批次、完成进度、取消；单批失败标明并提供“重试失败批次 / Retry failed batches”。取消后迟到结果不应用；已成功建议保留且来源可辨，不能把未完成批次显示成功。

- **AC-4 严格校验**：不存在/重复/越界/不连续编号、空结果、缺必要字段或违反研究门槛的结果都不能转为剪切；明确“分析结果无效 / Invalid analysis result”，提供重试。不得静默用原文或全句删除填补。

- **AC-5 候选展示**：每条显示原文、类别、原因和研究定义的可信信息，禁止把未经校准的分数伪称准确概率。时间轴红色待删标记配文字/图标；规则和语义建议来源分别可见但重叠时间不重复扣除。

- **AC-6 临时试听**：支持单条前后试听、勾选集合临时预览和回到正式版本，显示“预览，尚未应用 / Preview, not applied”；无建议显示“没有发现可剪除的语义口癖 / No contextual fillers found”。正常导出不包含待确认标记。

- **AC-7 编辑过期**：原文、时间戳或正式EDL发生相关变化时旧候选标“建议已过期，请重新分析 / Suggestions are outdated. Analyze again.”，应用禁用；不得用旧模型回复覆盖新的校对。

- **AC-8 确认或拒绝**：逐条/批量确认后才写EDL与操作历史；拒绝、取消不改正式项目。提交中禁用重复，失败保留旧结果及候选，重试有重复保护。来源相同的重复建议不能创建重复删除。

- **AC-9 历史与隐私**：重开后可预览/回退已确认剪辑历史，不回滚后续文字校对；日志不含模型密钥或完整敏感字幕，错误诊断脱敏。调用失败不跳过人工确认直接自动删。

- **AC-10 研究门槛与实测**：F-0008研究报告中的可用模型/类别/质量门槛作为验收引用。真实API与两段原始口播验证，不把mock测试当模型可用；若研究改变范围或表明不可用，退回本PRD重审。桌面/Web同Host遵守相同门禁。
