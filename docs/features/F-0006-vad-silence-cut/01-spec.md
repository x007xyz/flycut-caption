# F-0006 VAD 去静音：需求说明

> 2026-11-05 流程调整：由原立项（01-intake）和产品文档（02-prd）合并而成，内容未改；两者都已由维护者确认。

## 立项

### 来源

### 要解决的问题

现有智能剪空白按字幕句间空隙判断，漏掉句内停顿，切点没有余量，口播容易吞字或节奏过紧。

### 目标用户与场景

对照 `docs/10-product/vision.md`：10–60 分钟中文口播创作者，字幕校对、粗剪、导出并继续发布。范围内各操作应让用户能检查结果，不能为了自动化隐去失败或覆盖选择。

### 竞品怎么做

资料来源为已存在的 vision.md 及所属 Epic（读取日期 2026-11-05）。Descript 为文本编辑/校对参考，剪映为后续精剪目标；各产品在本需求的具体版本、限制和行为本轮未外部核实，均待核实，不编造效果或价格。调研项会在研究阶段记录一手来源和日期；功能范围不依赖未经核实的竞品内部实现。

### 获客价值

对应愿景的创作者教程、开源社区与留存渠道：展示真实完成的字幕/粗剪工作流。核心是节省重复劳动、保持原始素材和用户确认权；调研结果不直接当成功能宣传。

P1。按已确认路线图阶段一推进；文档可并行准备，开发/调研仍遵守依赖门禁。

frontmatter 的 depends_on 是脚本门禁；外部接口、真实配置和素材条件也必须在 PRD/研究计划列为前置条件，不能通过省略依赖绕过。

### 建议范围

- 基于真实人声检测找停顿，优先复用已内置的 FSMN VAD 或可用 Silero VAD，模型选择遵守 vad 角色能力。
- 可调最短静音时长、切点前后余量，选择删除或压缩停顿；通过有效字词时间戳保护发音边界，不按字数猜切点。
- 提供分析、预览、逐条或整体确认，确认后写 F-0005 的 EDL，支持撤销；切点短淡入淡出及桌面 Host 实际导出同步验证。

#### 不做

## 产品需求

### 背景

2026-11-05维护者批量确认立项，并明确剪辑建议应先标红/预览、确认后删除，操作历史可回退。本PRD将立项范围落实为可验证行为，不把研究结论或外部服务假设当成事实。所属候选与来源见01-spec.md。

### 目标用户与竞品

10–60分钟中文口播的个人创作者。竞品定位沿用vision.md，具体功能/版本未外部核实均待核实；本PRD以已批准用户任务为依据，不承诺竞品内部协议兼容。

### 范围

#### 做

- 用可用的 vad 角色模型检测真实人声；复用内置支持，参数可调，分析后标记/预览/确认。
- 支持删除停顿或压缩停顿、字词切点保护、音频切点平滑，预览及实际导出一致。
- 自动剪辑建议统一遵守修订后的 F-0005：建议是临时层，时间轴标红并有文字/图标；临时预览不修改正式 EDL/字幕删除状态，未确认内容不进入正常导出。逐条/批量确认才提交正式剪辑和持久化操作历史；取消只移除标记。历史可在重开后预览和回退，回退先确认并保留新记录。历史回退只恢复剪辑决策，不撤回后来完成的文字校对。

#### 不做

新的 ASR、语义去口癖、视频转场、多轨、变速；不更改旧“智能剪空白”的默认检测算法或入口。

### 用户故事

作为口播创作者，我希望先看见将被剪掉的停顿、试听后再确认，并能从操作历史找回原来的节奏。

### 验收标准

桌面端优先，Web开发模式连接同一Host验证共用业务；Cloud连接/续传另需真实远程环境。ASR Provider无关的功能不得按Provider写死分支；字词精确剪切仅看通过校验的实际结果。每个新增界面状态覆盖明暗主题与中英文，关键文案如下；测试名称带F-0006/AC编号。

- **AC-1 能力入口**：当用户打开“去静音 / Remove silence”时，显示可用VAD模型和参数；无可用模型显示“没有可用的人声检测模型 / No voice detection model available”及设置入口，分析按钮不可用。不得静默改用字幕间隙冒充VAD。

- **AC-2 参数**：建议默认最短静音0.5秒、前后保护余量各0.15秒，默认模式“压缩停顿 / Shorten pauses”，保留0.25秒；可切为“删除停顿 / Remove pauses”。只接受有限非负数，最短静音须大于0。保留长度不应超过原停顿；不足以剪的区间不产生候选。非法输入就地显示“请检查参数 / Check these settings”，禁止分析。

- **AC-3 分析状态**：点击“分析 / Analyze”只启动一次任务，显示进度和“取消 / Cancel”。分析失败显示“分析失败，请重试 / Analysis failed. Try again.”；取消或迟到响应不改变正式剪辑，也不把未完成结果自动应用。参数或源编辑变更后旧候选过期。

- **AC-4 建议标记**：分析成功后显示候选数、预计减少时长、每段起止与原因；时间轴待删部分标红并带“待确认删除 / Pending deletion”。无候选显示“没有可移除的停顿 / No pauses to remove”，可调参数重分析，确认按钮不可用。

- **AC-5 临时预览**：用户可切换“预览剪辑效果 / Preview proposed cuts”和“当前已确认版本 / Current confirmed cuts”，显示“预览，尚未应用 / Preview, not applied”；只试听勾选候选的临时结果。点击取消退出预览并清除本轮标记，普通导出仍只用正式EDL。

- **AC-6 切点保护**：可靠字词时间戳存在时，候选不能切入其发音区间；没有或不可靠时显示“缺少可靠字词时间戳，疑似发音边界不默认剪切 / Reliable word timestamps are unavailable. Uncertain speech boundaries will be kept.”。拿不准的候选不可默认勾选或精确执行，不能按字数猜时间。

- **AC-7 确认应用**：逐条确认或“应用选中建议 / Apply selected suggestions”前重查基准版本；过期显示“建议已过期，请重新分析 / Suggestions are outdated. Analyze again.”。提交期间禁用重复操作；成功原子写EDL和一条操作历史，失败保留原结果和候选，显示“应用失败，请重试 / Cannot apply cuts. Try again.”。

- **AC-8 导出与平滑**：确认后预览和Host导出同一保留区间。音频接点默认5ms淡出/淡入，不增加或缩短EDL目标时长、不改变源媒体；可关闭平滑。停顿压缩只去除选中停顿的一部分，不把发音加速；无音轨时明确不可分析，不能伪造成功。

- **AC-9 历史回退**：当前会话可撤销确认操作，重开后仍从F-0005历史预览/回退该剪辑；回退不撤销后来文字校对。原素材缺失或历史损坏时保留现状态并提示，不假称恢复音频。

- **AC-10 两端与边界**：桌面真实模型分析并导出，Web同Host得到同一候选/确认结果。全删或无有效区间沿用F-0005禁用导出；多次分析/应用同区间不重复扣时，原始媒体不可修改。

### 成功指标

至少两段未剪辑原始口播含句内停顿：逐候选听校并记录误切/漏切，确认前后/撤销后核对EDL和声画；实测淡入淡出、压缩与删除两种模式，真实导出不吞字。
