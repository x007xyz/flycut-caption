# F-0058 Web 与桌面共用自动化验收：设计

## UI / UX

无界面改动。测试通过现有项目列表、字幕文本框、保存和返回入口完成操作。

## 技术方案

- 测试入口位于 `tests/acceptance/`。用 WebdriverIO 执行同一个字幕保存用例，Web 连接 ChromeDriver，桌面连接真实 WKWebView 的内嵌 WebDriver。只使用标准 WebDriver 命令，不注入模拟 Tauri IPC。
- 每次启动用临时 HOME 和独立测试项目；通过现有 Host RPC 创建项目及固定字幕，再从界面修改。读取 Host 的正式编辑快照确认写入，离开后从项目列表重开并核对文本。Web 和桌面分别生成证据。
- 桌面 WebDriver 通过默认关闭的 Cargo feature 编译，仅测试构建注册；使用测试标识、独立数据目录、明确的构建绝对路径及回环端口。驱动启动后校验其监听进程。常规打包不含该 feature、测试 IPC 或权限。
- 独立脚本复制并启动不带驱动的候选包，等待随包 Host 发布连接信息。使用生成的短片，经现有上传和导出 API 验证 Skia 烧录。用 ffprobe 检查音视频轨及时长，用固定黑底上字幕区与对照区的像素变化断言字幕画面。通过临时副本移除随包 Node 或字幕字体，分别断言启动阶段和导出阶段失败。
- macOS CI 构建两种候选，执行 Chrome、Tauri UI 和打包冒烟三个目标并上传日志。现有 Playwright 配置和发版流程继续独立运行。

### 接口与数据

只复用 Cordis Host 现有 RPC 和导出数据契约。夹具无用户数据、无需模型和外部 API。遵循前端、Cordis Host、Tauri 子系统规范及已确认架构边界。

### 备选方案

保留现有 Playwright 负责 Web 回归；直接拿 Chromium 测试替代桌面无法覆盖 WKWebView 和随包 Host。使用嵌入式驱动的标准 WebDriver 端点，可以复用同一套 WebdriverIO 操作而不添加 JS 测试桥接或权限。

## 自行决定的事项

- 驱动入口只用于显式测试构建，日常 debug 构建也不会默认监听。
- 用合成短视频和已知字幕做像素断言，避开真实转写、系统字幕及截图识别的不确定性。

## 风险与回退

先验证驱动兼容性、回环绑定和本机/CI 图形会话，保留具体启动与断言日志。桌面测试及冒烟分开启动，避免误连同机旧版。撤回测试脚本和可选构建项不影响业务数据。

## 实现清单

- [x] 固定项目夹具、Chrome 会话和共用字幕保存用例，读取真实 Host 快照验证。
- [x] 独立桌面测试构建和 WKWebView 会话，运行同一用例并验证默认构建不带驱动。
- [x] 无驱动包启动和硬字幕导出，加入 Node 与字体缺失的反向验证。
- [x] macOS CI 与失败证据，保留既有 Playwright 回归入口。

## 验证计划

| AC | 平台与入口 | 断言 |
|---|---|---|
| AC-1 | Chrome / macOS Tauri，分别执行同一 WebdriverIO 用例 | 打开固定项目、改一条字幕、真实 Host 读到修改、返回后重开仍存在 |
| AC-2 | 独立 macOS 桌面测试包和默认候选包 | 本次构建绝对路径、测试标识与隔离数据；常规构建未注册驱动 |
| AC-3 | macOS 无驱动候选包冒烟 | 随包 Host 就绪，MP4 音视频轨和时长、字幕像素；缺 Node 与缺字体分别在预期阶段失败 |
| AC-4 | macOS CI 和本机、既有 Playwright | 三目标分别记录结果和日志；现有 Web 测试入口保持可用 |

合并前按代码标准跑静态检查、单元和架构测试；未在真实环境执行的目标保留为 Not run。
