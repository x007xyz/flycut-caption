## 用户故事

作为使用FlyCut的口播创作者或调用其Host的Agent用户，我希望完成「Host项目操作CLI」的完整操作，以便解决上述场景中的重复劳动与不确定性，并保留对素材和正式修改的控制。

## 验收标准

专用行为AC-1起列出，随后界面生命周期AC同样是验收项，不得用共用状态测试代替专用行为验证。桌面端优先，Web复用Host；平台补测项按其指定平台验收。

- **AC-1**：CLI通过Host应用服务创建/读取项目、上传媒体、转写、获取建议和导出，支持帮助、机器可读JSON、明确退出码及任务状态查询；输入只用合法项目/资产ID。

- **AC-2**：配置引用Host保存的模型，不从浏览器读取Key，不在命令输出或日志泄露凭据；鉴权失败、模型未就绪和无Host连接有可操作错误。

- **AC-3**：剪辑建议只生成待审内容；删除项目/覆盖导出等操作生成客户端确认请求，未经客户端本人确认不能执行，命令行--yes或Agent参数不能绕过。

- **AC-4**：隔离Host从真实媒体上传到转写与新文件导出完整走通，结果和UI一致；Ctrl+C/断线后可查询任务，重复提交不重复执行有副作用操作。

- **AC-5**：**帮助与空结果**：终端提供help、子命令用法和示例；空列表返回合法空JSON数组及成功退出码，不虚构项目；缺目标/模型返回机器可识别错误和下一步，无需新建CLI设置页面。

- **AC-6**：**任务运行中**：JSON模式以稳定任务ID查询排队/运行状态，日志进stderr不污染stdout；交互终端可显示进度，Ctrl+C停止等待并说明Host任务是否仍运行。

- **AC-7**：**正常结果**：创建/转写/新文件导出返回对象ID和可查询状态，只有Host核验成功才标完成；UI重开能读取相同数据，退出码0只表示该命令承诺的提交/完成阶段成功。

- **AC-8**：**失败与确认**：鉴权失败、目标不存在、参数错误、版本冲突及连接失败返回稳定错误码、非零退出码，不泄密；破坏性请求返回待客户端确认状态，未确认不执行。保存结果不确定时查询，避免重复提交。

- **AC-9**：**真实验证**：真实终端驱动隔离Host完成AC-1至AC-4，客户端确认状态覆盖中英文/明暗主题；CLI帮助与JSON契约有自动验证，不要求终端做主题截图。

## 成功指标

CLI真实闭环完成、JSON可解析、退出码可区分失败；未经客户端确认的破坏性执行数为0。

验收记录输入素材、模型/接口/平台版本、命令和结果；版本复盘按实测记录比较。没有埋点不编造线上转化或留存数字。
