## 自行决定的事项

<!-- 开发中自己决定的事：决定了什么、为什么、影响哪条 AC。验收时汇总进测试报告 -->

- 按本次执行要求，真实性能测试使用 5173 隔离端口；设计基线的 5174 仅作 before 记录，产品端口未改。
- `scrollToIndex` 在后续行高测量后会继续校正最多 24 帧，直到目标稳定；全量翻译使所有行变为双语时，单次按估算总高定位无法到达末尾。
- 播放跟随只在当前 chunk ID 变化时触发，最新可见性/手动滚动判断通过 ref 读取；这避免旧当前句在查找滚动后把列表拉回顶部。
- 首次播放跟随曾把 `manualScrollRef = 0` 当成页面开始时的手动滚动而静默抑制 3 秒；初始值改为负无穷，并由 AC-8 E2E 覆盖。
- 真实 COSCUP 拼接数据和媒体由 `tests/e2e/lib/longTranscript.ts` 与 Web/Tauri 基准共用；E2E 里的确定性 1,173 行数据只作为 UI 夹具，不用于声称真实 AC 数据通过。
- Tauri 开发基准会校验 1,173 句 / 15,014 字词和媒体时长，并在本机复制被忽略的 Node 动态运行库；复制资源不进入提交。

## 与设计的偏差
