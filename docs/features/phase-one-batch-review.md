## 本轮请确认的范围建议

1. **剪辑建议都需人工确认**：VAD 分析后预览再应用；规则层只提供可检查的候选，“就是/那个/然后”等语义词不按词表默认删除。无可靠字词时间戳不进行精确字词剪切，不擅自整句替代。语义层的模型、阈值、协议性能门槛等待 F-0008 研究结果，不能先确定未经验证的技术结论。
2. **剪映先验证再承诺**：F-0010 先核实维护者实际使用的剪映桌面系统与版本，首发支持矩阵、是否打包媒体及样式降级随研究结论确认；本轮不承诺 CapCut/全版本兼容。F-0011 只创建新草稿，不覆盖已有草稿。
3. **校对先聚焦当前视频原文**：不做正则/跨项目替换，不自动改译文或剪辑时间；AI纠错先逐条审阅，默认不直接覆写用户新校对，不在本次顺手重构翻译或模型设置。
4. **远程Host建议拆分**：E-08/6 候选范围包含多个独立可交付单元，按流程建议退回 Epic 拆为“Cloud客户端连接与会话”和“大文件断点续传及断线恢复”。F-0014 暂停在立项审阅，不擅自把大范围送进开发；维护者同意后调整 Epic、分配新增编号并分别写 PRD。阶段一功能两端对齐作为汇总验收，不能仅凭连接成功宣称所有能力完成。

F-0014 若拆为两个功能，后续本批功能 PRD 数量将从 7 份变为 8 份；两个调研走研究报告，不写 PRD。拆分方案本轮未经维护者确认，尚未修改 Epic 范围。
