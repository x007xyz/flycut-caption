## 立项

### 要解决的问题

长口播同一专有名词反复识别错时，用户需要逐条点击修改；缺少查找、逐条定位和可撤销批量替换，校对效率低。

### 目标用户与场景

对照 `docs/10-product/vision.md`：10–60 分钟中文口播创作者，字幕校对、粗剪、导出并继续发布。范围内各操作应让用户能检查结果，不能为了自动化隐去失败或覆盖选择。

### 竞品怎么做

资料来源为已存在的 vision.md 及所属 Epic（读取日期 2026-11-05）。Descript 为文本编辑/校对参考，剪映为后续精剪目标；各产品在本需求的具体版本、限制和行为本轮未外部核实，均待核实，不编造效果或价格。调研项会在研究阶段记录一手来源和日期；功能范围不依赖未经核实的竞品内部实现。

### 获客价值

对应愿景的创作者教程、开源社区与留存渠道：展示真实完成的字幕/粗剪工作流。核心是节省重复劳动、保持原始素材和用户确认权；调研结果不直接当成功能宣传。

### 优先级

P0。按已确认路线图阶段一推进；文档可并行准备，开发/调研仍遵守依赖门禁。

### 建议范围

- 当前视频原文中查找，显示命中数量、高亮和上一/下一处定位，支持快捷键逐条校对。

- 编辑输入焦点、查找框与播放器快捷键冲突需明确规则；修改只影响文本，不改源时间戳和剪辑区间。

#### 不做

## 产品需求

### 背景

2026-11-05维护者批量确认立项，并明确剪辑建议应先标红/预览、确认后删除，操作历史可回退。本PRD将立项范围落实为可验证行为，不把研究结论或外部服务假设当成事实。所属候选与来源见01-spec.md。

### 目标用户与竞品

10–60分钟中文口播的个人创作者。竞品定位沿用vision.md，具体功能/版本未外部核实均待核实；本PRD以已批准用户任务为依据，不承诺竞品内部协议兼容。

### 范围

#### 做

- 当前视频未删除的原文查找、高亮、上一/下一处定位、单处及全部替换；保持句/词ID和时间戳。
- 快捷键逐条校对、输入焦点保护、批量替换预览和一次撤销；与已有项目保存衔接。

#### 不做

正则、跨视频/项目替换、自动替换译文、AI重写、改变EDL或时间戳、重新识别。

### 用户故事

作为口播创作者，我希望找到并批量改正反复出现的专有名词，同时能检查数量、撤销误替换。

### 验收标准

桌面端优先，Web开发模式连接同一Host验证共用业务；Cloud连接/续传另需真实远程环境。ASR Provider无关的功能不得按Provider写死分支；字词精确剪切仅看通过校验的实际结果。每个新增界面状态覆盖明暗主题与中英文，关键文案如下；测试名称带F-0012/AC编号。

- **AC-1 查找入口**：快捷键Cmd/Ctrl+F在字幕编辑场景打开“查找 / Find”，普通非编辑页面保留浏览器行为。输入查询后在当前视频未删除原文显示匹配及“{current}/{total}”；输入为空不匹配所有字符。

- **AC-2 匹配规则**：默认普通文本、不区分英文大小写，支持“区分大小写 / Match case”开关；中文按实际字符匹配，不隐式繁简/同音替换。不同句子之间不跨句拼接命中，查询字面意义解释，不执行正则。

- **AC-3 命中定位**：上一/下一处可循环，定位字幕并更新选择；用户可试听对应原时间，但查找本身不自动改播放模式或删除内容。命中高亮除颜色外有可访问名称。无结果显示“没有匹配结果 / No matches”。

- **AC-4 单处替换**：展示“替换为 / Replace with”和单处替换按钮；替换只改当前命中原文，空替换文本允许但需在预览显示删除文字，不等于剪掉音视频；时间戳、ID、译文和EDL不变。

- **AC-5 全部替换预览**：点击“全部替换 / Replace all”先显示命中数量、涉及字幕及替换前后预览，按钮“确认替换 / Confirm replacement”和取消；确认前原文不变，0命中禁用。查询或范围变化后旧预览失效。

- **AC-6 提交与冲突**：确认时核对原文版本，若已变化显示“字幕已更新，请重新检查替换 / Subtitles changed. Review replacements again.”；提交中禁用重复，失败保持原文并显示重试，不部分改完却报成功。

- **AC-7 撤销与保存**：一次全部替换作为一个文字编辑操作，当前会话撤销一次恢复该批原文；正式保存/失败/离开保护沿用项目服务。不把文字替换写成剪辑历史或取消用户已确认EDL。

- **AC-8 输入焦点**：在查找/替换/字幕输入或输入法组合中，Space、Delete及普通字符不触发播放器或删除片段快捷键。Esc先关闭当前查找/预览层，不擅自删除或取消保存；快捷键文字按平台显示。

- **AC-9 已删除与字词关联**：已删除内容不参加当前搜索/替换；恢复后按新状态重新查询。字词原时间和源ID不重排，无法可靠把改后文字对应到字词时禁止按字数猜时间，保持可编辑句级文本及既有精确剪切门禁。

- **AC-10 两端与性能**：桌面和Web当前视频行为一致；60分钟真实字幕至少20次查找/替换，记录耗时；切换视频或关闭项目清空旧命中/预览，迟到查询不得改新视频。加载中显示“正在查找… / Searching…”且替换禁用；失败显示“查找失败，请重试 / Search failed. Try again.”。

### 成功指标

真实长口播完成多处名词查找、预览、替换与撤销；替换前后所有时间戳、删除决策、译文逐项相同，重开项目读到已确认文字。
