# F-0007 去口癖规则层：需求说明

> 2026-11-05 流程调整：由原立项（01-intake）和产品文档（02-prd）合并而成，内容未改；两者都已由维护者确认。

## 立项

### 来源

- 已确认 Epic 候选 E-06/3，对应路线图阶段一。批量编写日期：2026-11-05。
- 维护者原话：「是否可以一起确认，调用 subagent 同时处理多个任务，subagent 模型使用 deepseek flash」。本轮只准备可集中审阅的立项，不视为已批准各项产品细节。

### 要解决的问题

中文口播里的独立语气词和叠词卡顿需要反复手工定位，现有工具没有可检查、可批量确认的规则建议。

### 目标用户与场景

对照 `docs/10-product/vision.md`：10–60 分钟中文口播创作者，字幕校对、粗剪、导出并继续发布。范围内各操作应让用户能检查结果，不能为了自动化隐去失败或覆盖选择。

### 竞品怎么做

资料来源为已存在的 vision.md 及所属 Epic（读取日期 2026-11-05）。Descript 为文本编辑/校对参考，剪映为后续精剪目标；各产品在本需求的具体版本、限制和行为本轮未外部核实，均待核实，不编造效果或价格。调研项会在研究阶段记录一手来源和日期；功能范围不依赖未经核实的竞品内部实现。

### 获客价值

对应愿景的创作者教程、开源社区与留存渠道：展示真实完成的字幕/粗剪工作流。核心是节省重复劳动、保持原始素材和用户确认权；调研结果不直接当成功能宣传。

### 优先级

P1。按已确认路线图阶段一推进；文档可并行准备，开发/调研仍遵守依赖门禁。

### 依赖

F-0005 与 F-0001 完成。评测需要语气词保留率及短词时间戳误差，不依赖 F-0003 的未完成功能。

frontmatter 的 depends_on 是脚本门禁；外部接口、真实配置和素材条件也必须在 PRD/研究计划列为前置条件，不能通过省略依赖绕过。

### 建议范围

- 内置嗯、啊、呃、额等语气词表，识别单独语气词与叠词卡顿，输出原文、类别、原因、时间区间。
- 仅在字词时间戳通过校验时生成可执行的字词剪切，按类别或逐条确认，写同一 EDL，支持撤销。
- 没有可靠时间戳时明确说明不可精确剪切，允许保留建议但不得启用危险应用；规则层可离线运行。

#### 不做

LLM 语义判断、口误改口、挑选最佳重录、自动无确认删除；项目级自定义词表要在 F-0003 完成后适配，不作为本需求首发前提。

中：词表误判和短词切点不准会损伤口播。范围限制在建议与确认闭环，PRD 预计约10条 AC；质量门槛以 F-0001 结论设定。

### 不做的代价

### 验证与成功判断方向

### 待澄清的问题与建议

建议“就是/那个/然后”等存在语义用途的词不默认按规则删除，归入语义层；叠词只能作为候选而非判定口误。建议无字词时间戳时禁用精确应用，不回退成整句删除。

### 结论

### 批量确认补充：先标记后删除与历史回退

自动分析只产生待确认建议，时间轴标红并同时提供文字/图标标记；正式 EDL、项目删除状态和常规导出不改变。用户可试听/预览按建议剪出的临时版本，逐条或批量确认后才写正式 EDL。取消/拒绝清除建议标记。应用前重新核验原文和剪辑版本；失效建议不得执行。已确认剪辑写入可持久化的操作历史，允许重开后回退到历史版本；回退也记录为新操作，不静默覆盖其他窗口更新。本轮不承诺恢复已被永久删除的源媒体。具体历史选择、待确认状态和保存失败交互进入 PRD。

## 产品需求

### 背景

2026-11-05维护者批量确认立项，并明确剪辑建议应先标红/预览、确认后删除，操作历史可回退。本PRD将立项范围落实为可验证行为，不把研究结论或外部服务假设当成事实。所属候选与来源见01-spec.md。

### 目标用户与竞品

10–60分钟中文口播的个人创作者。竞品定位沿用vision.md，具体功能/版本未外部核实均待核实；本PRD以已批准用户任务为依据，不承诺竞品内部协议兼容。

### 范围

#### 做

- 独立语气词及叠词卡顿生成可核验的规则候选，内置嗯/啊/呃/额等词表，离线运行。
- 自动剪辑建议统一遵守修订后的 F-0005：建议是临时层，时间轴标红并有文字/图标；临时预览不修改正式 EDL/字幕删除状态，未确认内容不进入正常导出。逐条/批量确认才提交正式剪辑和持久化操作历史；取消只移除标记。历史可在重开后预览和回退，回退先确认并保留新记录。历史回退只恢复剪辑决策，不撤回后来完成的文字校对。

#### 不做

语义词的自动判定、LLM、句内改口、最佳重录选择；项目级自定义词表在F-0003完成后另适配，不阻塞首发。

### 用户故事

作为口播创作者，我希望把疑似语气词先标出来，试听保留语义后再删，误删能回退。

### 验收标准

桌面端优先，Web开发模式连接同一Host验证共用业务；Cloud连接/续传另需真实远程环境。ASR Provider无关的功能不得按Provider写死分支；字词精确剪切仅看通过校验的实际结果。每个新增界面状态覆盖明暗主题与中英文，关键文案如下；测试名称带F-0007/AC编号。

- **AC-1 时间戳门禁**：点击“去口癖 / Remove fillers”时，只有通过校验的字词时间戳能生成可执行精确候选；不满足显示“缺少可靠字词时间戳，无法精确剪除口癖 / Reliable word timestamps are required to cut fillers precisely.”，禁用应用，不回退为整句删除。

- **AC-2 规则范围**：独立语气词和叠词输出类别及触发文本；“就是/那个/然后”等有语义用途的词不因词表直接删除。叠词仅是候选，不断言一定是口误；不识别未被ASR转写出的声音。

- **AC-3 分析状态**：分析时显示“正在查找口癖… / Finding fillers…”和取消；失败可重试，取消及迟到结果不改剪辑。无结果显示“没有发现可剪除的口癖 / No removable fillers found”，不展示可点击的空应用按钮。

- **AC-4 候选标记**：列表显示原文、类别、原因、起止时间、勾选框；时间轴标红并有待确认图标和文字，悬停/键盘聚焦可查看原因。选择候选只修改临时层，不能写字幕deleted标记。

- **AC-5 试听预览**：提供单候选前后试听及整轮临时剪辑预览，显式显示尚未应用；取消候选恢复临时保留区间，不影响正式EDL。试听不得从头重新识别。

- **AC-6 逐条及分类确认**：支持逐条或按类别选中，再“应用选中建议 / Apply selected suggestions”；默认建议可选中但不得自动执行。应用前校验ID、时间范围和编辑基准，过期明确提示重新分析。

- **AC-7 重叠与应用失败**：重叠建议合并删除，重复确认不二次扣时。提交期间禁用重复按钮；失败显示“应用失败，请重试 / Cannot apply cuts. Try again.”，保留候选与原剪辑，不记录虚假的成功历史。

- **AC-8 语义保护**：每条候选可拒绝，拒绝不改源文本和剪辑；句子译文不自动猜测逐词删除，沿用F-0005已确认策略。保留原转写和媒体，用原ID映射，不按字数均分时间。

- **AC-9 持久历史**：一次确认作为一个剪辑操作，立即撤销恢复该轮，重开后可预览/回退历史；只标记但未确认的候选不产生正式删除历史或正常导出变化。

- **AC-10 真实质量**：使用F-0001已确认的原始口播与参考标注，记录规则误报、漏报、切点听感；桌面与Web同Host离线可完成，无模型API配置仍可用。达不到短词时间保护时保守保留，不把危险候选标默认可应用。

### 成功指标

人工标注两段原始口播，统计独立语气词/叠词候选误报与接受率；逐条试听、确认、导出并回退，正式EDL在确认前完全不变。
