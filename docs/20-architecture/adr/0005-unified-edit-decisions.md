# ADR-0005 统一原媒体编辑决策与派生时间映射

## 背景

F-0005 PRD 已确认：新操作只删除明确选择的区间，其余媒体保留；旧项目保持升级前视频导出效果；部分删除后的译文保留句子文本，由用户校对。当前预览、导出和字幕计算分散，不能继续各自推算删除时长。

## 决策

- 每视频一份原媒体坐标上的规范化删除并集，保留段取全媒体补集；核心在 shared/editing/edl，前后端共用。
- 计算/持久化使用带显式单位的整数微秒和半开区间；最终格式/编码边界才量化。非法输入拒绝，不静默裁剪。原始媒体、原转写时间戳及 ID 不变。
- 预览定位、统计、主副字幕 cue 和导出计划全部派生；deleted 标记只作投影/兼容字段，不能成为第二份导出真源。
- EDL 与用户编辑作为同一快照保存和撤销。启动导出捕获不可变快照，Host 校验源媒体及计划，拒绝矛盾输入；旧 RPC 参数不静默改单位或语义。
- 旧项目用固定 legacy 适配器重现升级前实际桌面 Host 导出结果，将其补集保存为兼容删除。显式区分新编辑语义和旧迁移，不捏造操作历史；格式版本按实施时的最新项目格式递增。
- 可靠字词映射决定原文部分删除能力，不按字数分配时间；译文不推测逐词对应。四种字幕格式及烧录共享同一 cue 投影。

## 备选方案

- 同时保存保留和删除集合：容易不互补，选单一真源。
- 每个消费者独立推算：重复当前问题，无法保证一致。
- 升级时全部套用新规则：可能改变旧成片，与确认的兼容要求冲突。
- 全链路先舍入到字幕毫秒/厘秒：丢失媒体精度，多个切点可能累计偏差。

## 后果

需迁移所有消费者、历史状态、项目持久化与旧格式，并实测帧级输出而非只比较计划。旧 Host 的单段尾裁剪 fast path 在新路径需验证修正；迁移仍以旧实际输出为准。精度、边界、非法数据、恢复入口和全部 AC 的设计见 F-0005/02-design.md。F-0002 验收前不开发；本 ADR 保持 proposed，技术选择由维护者在验收时审阅。
