# ADR-0010 语义剪辑建议使用词 ID 范围并由 Host 校验

## 背景

F-0008 的调研结论要求语义模型只生成候选，不生成时间戳或正式剪辑；规则层继续离线可用。当前转写已经有通过校验的 chunks/wordChunks，F-0005 的 EDL 是唯一正式剪辑快照，F-0007 的人工确认层允许先标记、试听、预览、逐条或批量确认。语义输出如果没有严格的词 ID 与区间校验，模型编造的编号、时间或整句范围会直接带来误删。

## 决策

语义剪辑候选以连续字词区间表达，只提交 startWordId 和 endWordId（可附带经核对一致的 wordIds）；时间戳只由 Host 从权威字词表派生。Host 在候选进入人工确认层前，整批校验编号存在、方向、连续性、目标范围、句边界、半句/空句、重叠/重复和 base；结构合法但 candidates 为空的响应表示没有候选。语义请求走现有 Host 文本任务，由 F-0056 Host AI settings 按 configId 解析已保存模型和密钥；RPC 与 job 输入只带 configId，不接受明文 Key，也不新建模型 Provider 角色或平行设置。规则层保留为无模型/失败时的离线基线。所有候选默认不自动应用，F-0008 未提供质量门槛的类别不得默认勾选。应用前再次比较 base 和正式 EDL/媒体时长。远程 Host 必须在发送前明确展示目标配置和文本范围；应用内置本地 LLM 不在本决定范围。

## 备选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| 词 ID 连续区间 + Host 校验 | 时间真源唯一；可解释、可测试、可复用现有确认层 | 前后端需共享协议和窗口构造 |
| 模型返回毫秒时间 | 接入直接 | 秒数/边界不可信，容易切到字中间或与转写漂移 |
| 模型返回全文替换 | 实现简单 | 无法保持原文/时间戳，误删与审计风险最高 |
| 前端自行校验后直接保存 | RPC 少 | 不满足 Host 业务边界，Workflow/Agent 无法复用同一安全门 |
| 继续由 RPC 传 AIModelConfig/Key | 兼容旧调用 | 违反已验收 F-0056，浏览器不得处理新请求密钥 |

## 后果

F-0009 需要维护共享校验器、窗口构造、Host 文本任务和批次状态；失败时只显示 invalid/partial，不把模型输出当作正式剪辑。规则层与项目格式保持不变，F-0043 可复用同一候选身份与来源字段。AI 配置和 secret 的生命周期继续由 F-0056 唯一边界负责，F-0009 只消费 configId。由于 F-0008 尚无真实质量数据，本 ADR 只确认协议和人工确认边界，不确认默认模型、类别默认开启、准确率或成本；这些仍需真实评测。
