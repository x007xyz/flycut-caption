# E-07 长视频转短视频

## 要解决的问题

口播创作者录了一段长视频，想切成多条短视频发抖音、小红书、视频号，现在靠手动挑片段、手动改竖屏。

## 现状（2026-11-05）

- Host 已有 LangGraph 流水线（`server/plugins/langgraph.ts`）、编辑分析器注册表和 Agent 工具注册表；注册表里只有 `delete-silence`，没有片段评分和竖屏重构图。
- 流水线的 `analyze` 步骤只收集删除区间（`delete-range`），表达不了「从长视频里选出一段作为新短片」。

## 目标用户与竞品

- **目标用户**：把直播回放、播客、课程、长口播切成短视频的创作者。
- **竞品**：OpusClip（病毒性评分、ClipAnything、AI 重构图、品牌模板）、Vizard、Klap、剪映长视频转短视频。
- **差异**：字幕可逐条校对；每条短片自动带上去静音、去口癖的结果；桌面端本地处理，不用上传；每条短片可导出剪映草稿（复用 E-06/6）。

## 做完是什么样

- 自动推荐一批精彩片段，附理由和评分，用户挑选、调整边界后确认。
- 每个片段一键导出竖屏短视频，带字幕和特效，主体自动跟随。
- 每条短片有 AI 生成的标题、简介、话题标签候选。
- 可以批量导出，在 Host 后台执行。

## 设计要点

- **短片是项目里的产出物**（E-02 数据模型已预留）：原视频上的一个时间范围 + 该范围内的编辑决策（复用 E-06/1），不复制媒体。
- **片段边界落在句子边界上**，不切半句。
- **流水线增加「片段建议」输出**，和删除区间并列，同样先给建议、用户确认后才生成短片。
- **裁切路径的预览和导出一致**，和 E-03/1 选定的渲染架构一起考虑。

## 不做

文生视频；自动发布到平台；自动配 B-roll 素材（以后可能单独立项，渲染架构由 E-03/1 预留）。
