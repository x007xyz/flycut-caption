## 发布说明

### 中文

FlyCut Caption 2.1 把“上传 → 转写 → 删字幕剪视频 → 导出”扩展成完整的口播后期工作台：

- **项目**：项目保存在本机 Host，支持项目管理、自动保存与冲突提示、崩溃恢复、备份导出/导入，长视频打开更快。
- **转写**：推荐默认离线模型并引导下载（SHA-256 校验、断点与取消）；热词与专有名词；标点与断句优化；说话人区分与按说话人筛选字幕。
- **按文字剪辑**：统一的剪辑决策（EDL）与剪辑历史；VAD 去静音；去口癖（规则层 + AI 语义层）；导出剪映草稿；校对工具与按差异确认的 AI 纠错。
- **字幕样式**：共用字幕图形层（预览与导出一致）、逐字高亮、关键词强调、平台风格预设与安全区、自定义样式保存复用。
- **多语字幕**：多语言字幕轨道、带上下文的分批翻译、项目术语表、多语言 SRT 与软字幕轨导出。
- **配音**：单条与整段配音（自动对齐时间轴）、配音混音导出、人声/背景声分离、多说话人配音、授权的项目音色克隆、可接入的 TTS Provider。
- **长视频转短视频**：短片推荐与人工确认、竖屏字幕短片导出、主体跟随、Host 后台批量导出、标题简介与话题标签生成。
- **平台与接入**：Cloud 客户端连接、大文件断点续传、AI 模型配置与密钥保存在 Host、Host 项目 CLI、MCP Server（可让 Agent 调用剪辑建议工具）、桌面安装包签名与公证。

已知限制：
- Windows 与 Linux 无界面环境的字幕渲染尚未实机补测（F-0029 规划中）；桌面端暂无自动更新（F-0054 规划中），升级需手动下载安装包。
- 声音克隆仅限已授权的项目说话人；口型同步不在本版本。
- 字词时间戳强制对齐不做（见 F-0022 结论）。

### English

FlyCut Caption 2.1 turns "upload → transcribe → cut by deleting subtitles → export" into a full post-production workspace for talking-head creators:

- **Projects**: stored on the local Host, with project management, autosave and conflict handling, crash recovery, backup export/import, and faster opening of long videos.
- **Transcription**: recommended offline default model with guided, checksum-verified, resumable download; hotwords; better punctuation and sentence splitting; speaker diarization and per-speaker filtering.
- **Text-based editing**: unified edit decisions (EDL) with history; VAD silence removal; filler-word removal (rules + AI); CapCut/Jianying draft export; proofreading tools and diff-based AI correction review.
- **Subtitle styling**: shared subtitle graphics layer (preview matches export), word-by-word highlight, keyword emphasis, platform presets with safe areas, reusable custom styles.
- **Multilingual subtitles**: multiple language tracks, context-aware batched translation, project glossary, multilingual SRT and soft-subtitle export.
- **Dubbing**: per-cue and full-track dubbing aligned to the timeline, mixed audio export, vocal/background separation, multi-speaker dubbing, authorized project voice cloning, pluggable TTS providers.
- **Long-to-short**: recommended clips with manual confirmation, vertical subtitled clip export, subject following, background batch export on the Host, generated titles, descriptions and hashtags.
- **Platform & integrations**: Cloud client connection, resumable large uploads, AI model settings and keys stored on the Host, Host project CLI, MCP server for agents, signed and notarized desktop installers.

Known limitations:
- Subtitle rendering on Windows and headless Linux has not yet been validated on real machines (F-0029 planned); no desktop auto-update yet (F-0054 planned) — upgrade by downloading the new installer.
- Voice cloning is limited to authorized project speakers; lip sync is not included.
- Forced word-timestamp alignment is not planned (see F-0022).

## 发版闸门

2026-11-19 在 `codex/baseline-20261113`（74ad688）上预跑 `pnpm release --dry-run`，尚未满足发版条件：

```text
❌ 在 main 分支：当前分支是 codex/baseline-20261113
❌ 工作区干净：有 4 个未提交的改动
❌ HEAD 已推送到 origin/main：origin/main 是 ad00f066
❌ tag v2.0.2 尚不存在：本地已有该 tag            ← 版本号尚未改为 2.1.0
✅ 版本号一致：2.0.2
✅ Cargo.toml 可解析
✅ 签名与发版流水线配置完整：entitlements/app.plist / win:sha256
❌ 该 commit 的 CI 已完成且全绿：workflow ci.yml not found on the default branch
```

剩余步骤（需维护者同意后执行）：origin/main 是本分支的祖先，可快进合并 → 推送 main（ci.yml 随之进入默认分支并运行）→ 三处版本号改为 2.1.0 并 `cargo check` → CI 全绿后重跑 dry-run，结果贴在这里 → 维护者同意后 `pnpm release`。

本地已通过：`pnpm lint`（0 错误、3 个 warning）、`pnpm tsc -b --noEmit`、`pnpm check:host`、`cargo check`、`pnpm test`（144/0）、`pnpm test:architecture`（209/0）。

平台：macOS（签名 + 公证）、Windows（sha256 + RFC 3161 时间戳），由 `release.yml` 打包；Web 随 Host 发布；不再发布 npm 包。

回滚：发布后发现严重问题时，在 GitHub Release 把 v2.1.0 标为 pre-release/撤下资产，让用户回装 v2.0.2 安装包；项目数据是本版本新增的 Host 存储，v2.0.2 没有项目功能，预计回装不会读写它（发版前需实机核实）。修复走 v2.1.1。
